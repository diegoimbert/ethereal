# Security policy

## Reporting a vulnerability

Report vulnerabilities privately, never in a public issue, pull request or discussion.

Use GitHub private vulnerability reporting: the repository's **Security** tab, then
**Report a vulnerability** ([direct link](https://github.com/diegoimbert/ethereal/security/advisories/new)).
If that form is not available to you, contact [@diegoimbert](https://github.com/diegoimbert)
privately on GitHub and ask for a private channel.

Please include what is affected (desktop, web, `ether-server`, the plugin sandbox), the steps
to reproduce, and the impact you expect.

## What to expect

- An acknowledgement within a few days.
- A fix on `dev`, then in the next release, with credit in the advisory unless you prefer not.
- Please give us a reasonable time to ship the fix before disclosing it.

## Scope

The desktop app and its plugin sandbox, the web app and `ether-server`. Third-party plugins
loaded by the user are out of scope.
