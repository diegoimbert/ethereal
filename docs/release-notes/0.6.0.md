### Mobile
- Phones and touch-only tablets get a mobile interface: touch navigation (pan, pinch zoom), clips, tracks, selection, the clip editor, the mixer, automation, projects and settings.

### Documentation and guided tours
- User documentation at **/docs**, with search and the keyboard shortcuts, in English and French.
- A guided tour on the welcome screen: record audio.

### Plugins
- Plugin format filters (CLAP / VST3 / AU) in the browser; a rescan can reload a missing plugin.
- Plugins report their own value text on knobs; absurd latencies are clamped and stuck loads are freed.

### Editing
- **Automation lanes** work like the arrangement: range copy / cut / paste / duplicate / delete, press to create points, Shift for fine values. The tempo lane edits the same way.
- Return tracks from the UI, pre/post-fader per send.
- Every undo step has a readable name; flattening and clearing expression lanes ask first.
- Bounce a time selection to new tracks; reversing an audio clip plays the same material backwards.
- A shortcuts editor in Settings; every shortcut hint follows your keymap.
- Version history keeps tiered backups, and "Save snapshot…" (Mod+Alt+S).
- Multi-channel audio inputs and per-track MIDI input filters.

### Import and export
- **MIDI**: import MIDI files as clips; export clips and tracks as MIDI.
- Export to MP3 320 kbps, several formats from one render.

### Languages
- Ethereal is available in **French**: the whole interface, the docs and the macOS menu bar follow the language setting.

### Web app
- The open project is in the URL, so a reload reopens it; the tab title is the project's name.
- Only one tab edits your projects at a time; a hidden or closing tab saves first.
- The browser is asked to keep your projects permanently.

### Reliability
- A lost audio output device is detected, reported, and recovered.
- Recording is never silently lost when switching projects; quitting saves plugin states.
- No stuck notes when switching devices; dialogs, drags and exports can't get stuck.

### Security
- A Content-Security-Policy for the web and desktop apps.
- Imported projects and archives are bounded in size and nesting, so a malformed file can't exhaust memory or crash the app.

### Performance
- Reverb impulse responses are prepared off the audio thread on the web.
- The mobile timeline renders at a capped pixel ratio.
