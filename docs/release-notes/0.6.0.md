> **If you installed v0.5.1 or earlier on desktop, reinstall once from https://ethereal.ws/download: older versions can't find updates (the updater now reads the public releases repository).** From this version on, updates install from the app.

### Live sharing
- Joining is more reliable: every step of a join has a timeout and a clear message, and a refused guest is told why (the member limit or a full session).
- **Test my connection** checks whether you can reach a session, including through the relay.
- The relay (TURN) server is production-ready, with a separate relay pairing per guest, so people behind strict networks can join.
- Listen guests can solo and mute tracks for themselves, and the host can hide devices from listeners.
- Follow a peer in the piano roll; the "allow editing" switch is remembered.
- "Play with": your engine, no engine (view only), or a participant's.

### Static shares
- A shared link opens the project in the app itself, read-only: the arrangement, the mixer with moving meters, and the stems.
- MP3 320 kbps for listening, lossless FLAC downloads, stems load on demand, and a publish can be cancelled.
- Advanced: point the app at your own share storage (Settings > Advanced).

### Mobile
- Phones and touch-only tablets get a mobile interface: touch navigation (pan, pinch zoom), clips, tracks, selection, the clip editor, the mixer, automation, projects, sharing and settings.

### Documentation and guided tours
- User documentation at **ethereal.ws/docs**, with search and the keyboard shortcuts, in English and French.
- Guided tours on the welcome screen: jam with your friends, record audio, bring a project from another DAW.

### Plugins
- **Explore plugins**: one-click installs of open-source plugins from a signed catalog, and links to freeware.
- Plugin format filters (CLAP / VST2 / VST3 / AU) in the browser; VST2 and VST3 editors on Linux; a rescan can reload a missing plugin.
- Plugins report their own value text on knobs; absurd latencies are clamped and stuck loads are freed.

### Editing
- **Automation lanes** work like the arrangement: range copy / cut / paste / duplicate / delete, press to create points, Shift for fine values. The tempo lane edits the same way.
- Return tracks from the UI, pre/post-fader per send.
- Every undo step has a readable name; flattening and clearing expression lanes ask first.
- Bounce a time selection to new tracks; reversing an audio clip plays the same material backwards.
- A shortcuts editor in Settings; every shortcut hint follows your keymap.
- Version history keeps tiered backups, and "Save snapshot…" (Mod+Alt+S).
- Multi-channel audio inputs and per-track MIDI input filters.

### Import and export
- **MIDI**: import MIDI files as clips; export clips and tracks as MIDI.
- Export to MP3 320 kbps, several formats from one render; Ableton Live Set export maps built-in effects to Live's stock devices.
- Many import fixes for Ableton Live, FL Studio, REAPER and DAWproject files.

### Languages
- Ethereal is available in **French**: the whole interface, the docs and the macOS menu bar follow the language setting.

### Web app
- The open project is in the URL, so a reload reopens it; the tab title is the project's name.
- Only one tab edits your projects at a time; a hidden or closing tab saves first.
- The browser is asked to keep your projects permanently.
- A download page at ethereal.ws/download.

### Reliability
- A lost audio output device is detected, reported, and recovered.
- Recording is never silently lost when switching projects; quitting saves plugin states.
- No stuck notes when switching devices; dialogs, drags and exports can't get stuck.
- Report an issue from the status bar.

### Security
- A Content-Security-Policy for the web and desktop apps.
- Imported projects and archives are bounded in size and nesting, so a malformed file can't exhaust memory or crash the app.
- Live sharing re-checks permissions when a guest is accepted, and the share endpoints validate what they receive more strictly.
- A static share link can't be reclaimed by someone else after it is unpublished.

### Performance
- Reverb impulse responses are prepared off the audio thread on the web.
- Peers' pointers stop redrawing once they settle; the mobile timeline renders at a capped pixel ratio.
