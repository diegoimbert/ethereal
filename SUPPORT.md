# Getting help

- **Using Ethereal:** start with the user documentation at
  [ethereal.ws/docs](https://ethereal.ws/docs) (also built into the app).
- **Questions and chat:** join the [Discord](https://discord.gg/jSKkuqpQ2b).
- **Bugs:** open an issue with the
  [bug template](https://github.com/diegoimbert/ethereal/issues/new?template=bug.yml), after
  searching the existing issues.
- **Feature requests:** use the
  [feature template](https://github.com/diegoimbert/ethereal/issues/new?template=feature.yml).
- **Security problems:** never in public; see [SECURITY.md](SECURITY.md).
- **Commercial licensing:** see [LICENSING.md](LICENSING.md).

Ethereal is maintained by one person, so an answer can take a few days. There is no paid
support.
